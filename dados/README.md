# Dados utilizados

Para esse trabalho usamos dados públicos do SP156, disponibilizados pela Prefeitura de São Paulo.

O arquivo que utilizamos foi o `arquivo-final-1-trim-26.csv`, que contém solicitações abertas entre janeiro e março de 2026.

No notebook, usamos os registros do tema "Animais" e selecionamos as solicitações que já foram finalizadas para analisar quanto tempo elas demoraram.

## Onde baixar o arquivo

O CSV pode ser encontrado neste link:

[Dados do SP156 - 1º trimestre de 2026](https://dados.prefeitura.sp.gov.br/dataset/dados-do-sp156/resource/75105148-4efd-48f3-8ae0-fc6c2adf7060)

Também vamos estar deixando o arquivo em `.zip` aqui no repositório, porque o CSV original tem mais de 100 MB e não caber no GitHub.
Se quiser usar essa versão, é só baixar o `.zip`, extrair o CSV e carregar ele no Colab normalmente.

## Como usar no Colab

Depois de baixar o CSV, é só abrir o notebook no Google Colab e carregar o arquivo pela aba "Arquivos", no lado esquerdo da tela.

O nome do arquivo precisa continuar sendo `arquivo-final-1-trim-26.csv`, porque é o que usamos pra identificar ele no código.

Depois disso, é só executar as células na ordem ou clicar lá em cima no "Executar tudo".
