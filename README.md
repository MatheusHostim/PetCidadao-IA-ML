# PetCidadao-IA-ML
O PET CIDADÃO é um projeto de proteção e bem-estar animal que reúne serviços de apoio, denúncias e animais desaparecidos. Porém este repositório foca na na parte de IA e ML, em que utilizamos dados públicos do SP156 para prever quais solicitações relacionadas a animais podem levar mais de 30 dias para serem finalizadas.
